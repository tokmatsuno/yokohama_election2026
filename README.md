# わたし挑戦！横浜市長選（2026）

2026年横浜市長選挙（10月18日投開票）の、非公式の投票ナビです。特定の候補者や政党を支持するものではありません。

## 機能
0. **AIに聞く**：各候補の主張をまとめた Gemini Notebook（NotebookLM）へのリンクと質問例
1. **考えの近い候補**：8つの争点に答えると、7人の候補それぞれとの一致度（%）を表示します。根拠と出典つき
2. **演説を聞きに行く**：告示日〜投票日のカレンダーと市内地図。見つけた街頭演説の予定を登録できます（ブラウザ内に保存）
3. **投票所を調べる**：郵便番号から区を判定し、期日前投票所（全38か所）の受付状況と、当日投票所の一覧ページを表示します
4. **選挙割マップ**：投票済証明書で特典がもらえるお店
5. **投票プラン**：いつ・どこで投票するか決めて、コピーやXで共有できます

## 公開手順（GitHub Pages）
1. GitHubで新しいリポジトリを作り、このフォルダの `index.html` と `README.md` をアップロード
2. Settings → Pages → Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

ビルド不要の単一HTMLです。外部サービスへの通信はGoogle Fontsのみ。

## 演説予定の自動収集（リアルタイム更新）
- `.github/workflows/rallies.yml` が **30分ごと** に `scripts/collect-rallies.mjs` を実行し、`data/rallies.json` を更新してコミットします
- ページは `data/rallies.json` を5分ごとに読み直し、「これからの演説」・カレンダー・地図に反映します
- 出典：
  - 有志の「横浜市長選2026街宣マップ」（https://yokohama-rally-map.base44.app/ ・公式発表ベース、運営 X:@hama4kansa2）
  - 藤川陣営の note（街頭演説スケジュール投稿）
  - `data/manual.json`（報道などで見つけたものを手で追加）
- 有効化：リポジトリの Settings → Actions → General → Workflow permissions を「Read and write」に。Actions タブから「演説予定の自動収集」を一度手動実行して動作確認してください
- 選挙が終わったら Actions タブでワークフローを Disable してください
- 街宣マップのデータを使う場合は、運営者へ一声かけておくと安心です

## データの更新
`index.html` の `<script>` 冒頭「DATA」にまとめています。
- `CANDS`：候補者情報・リンク
- `QS`：診断の設問と各候補の立場（`[スコア -2〜+2 または null, 確度 1 または 0.5, 根拠]`）
- `EARLY`：期日前投票所（座標はおおよそ）
- `RALLIES`：出典つきで確認できた演説予定
- `WARI`：選挙割（`status: "now"` 今回確認済み / `"past"` 過去に実施）

候補者の立場は2026年10月6日時点の公開情報（各候補の公式サイト・政策資料・報道）から整理したもので、要約や推定を含みます。選挙公報で確認のうえ、必要に応じて修正してください。

## 出典
- 横浜市選挙管理委員会 https://www.city.yokohama.lg.jp/city-info/senkyo/data/mayor/20261018_shicho.html
- 地図：国土数値情報（行政区域）を加工（niiyz/JapanCityGeoJson）
- 郵便番号：日本郵便 郵便番号データ（jp-zipcode-lookup 経由）

## 公職選挙法について
公開・運用する際は、選挙運動期間中の表現（特定候補への投票の呼びかけ等）にならないよう、中立的な表示を保ってください。投票日当日の更新・拡散の扱いにも注意してください。
